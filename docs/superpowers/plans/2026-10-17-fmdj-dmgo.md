# FMDj: DMGo support — plan

> Native execution (superpowers:executing-plans), one final review. The owner said "build" to the spec, 2026-10-17.

**Goal:** FMDj runs the owner's own DMGo ROM as well as LSDj (one at a time), with the white keys as DMGo's steps.

**Spec:** `docs/superpowers/specs/2026-10-17-fmdj-dmgo-design.md`

## Global Constraints

- Update path unchanged (gate 2b); gate 4 (`check_ble_boot.py --lsdj`) passes; mmio lint passes.
- Nothing from the DMGo ROM committed or published; ROM tests read `DMGO_ROM` and skip without it.
- LSDj's behaviour and its existing host results unchanged (the suite with `LSDJ_ROM`).
- Suite: `LSDJ_ROM=... DMGO_ROM=... sh tests/run_tests.sh` ends "ALL HOST TESTS PASSED".
- Match the code's style: comments in its voice, names `lsdj_*` / `LSDJ_*` in the unit.

## Review Focus

1. A step key while B (F#5) is held, or while a step is half done: no stuck B, no lost cursor.
2. An LSDj save in flash with DMGo installed (and the reverse): never loaded into the other program, never erased
   until REC.
3. Existing LSDj cartridge blocks and flash saves read exactly as before (no format or version change).
4. DMGo of another version (other global checksum): runs, buttons only, no memory writes.
5. The song page with DMGo: no LSDj parsing of a 32 KiB save; uploads of the wrong size refused.

## Tasks

### Task 1: programs, the save RAM, the cartridge
- `lsdj_gb.c`: `LSDJ_PROG_LSDJ` / `LSDJ_PROG_DMGO`, `lsdj_prog(const uint8_t *h)` (h = ROM bytes 0x134..0x14F)
  -> program or -1; `lsdj_prog_save(p)` (128 / 32 KiB); `lsdj_prog_steps(h)` (DMGo v1: global checksum 0xEE3C).
- `peanut_gb.h`: `cart_ram[0x1D] = cart_ram[0x1E] = 1`; rumble types: RAM bank & 0x07.
- `lsdj_cart.c`: `lsdj_cart_rom_check` by program; `lsdj_cart_need` / `_make` pack the program's save size; the
  reader unchanged (the unpack size comes from the header in lsdj.c).
- `lsdj_emu.c`: `emu_init` accepts both, `emu.sram_n` bounds the save RAM.
- Tests: `lsdj_gb_test.c` (programs from synthetic headers), `lsdj_cart_test.c` (a synthetic DMGo-shaped ROM:
  make, read, 32 KiB save), host run of `DMGO_ROM` (runs, saves).

### Task 2: the step keys and DMGo's keys
- `lsdj_gb.c`: `lsdj_notes_ab(prog)` (A/B bits); `lsdj_steps_t` with `lsdj_steps_press(s, notes_pressed)` and
  `lsdj_steps_frame(s, wram, b_held) -> keys to add`, the guard and the two frames (spec "Step keys").
- `lsdj.c`: A/B per program, NAV axes off for DMGo, the macro around `emu_frame`, splash lists both layouts (gate 4:
  the splash cannot read the block).
- `tests/lsdj/lsdj_host.c`: `-n FROM:STEP` (a white key pressed at FROM) and `-W FILE` (WRAM dump).
- Tests: unit (queue, guard, B held, two frames); `tests/lsdj/dmgo_test.py` with `DMGO_ROM` (key = real B in slot 1
  and 2, plays, cursor kept, title / menu / PICK A PAT ignored, other version ignored).

### Task 3: the store, the start, `info`
- `lsdj_store.c`: the record's `rsv[0]` becomes `prog` (0 = LSDj: today's records); `st->prog` from the newest;
  saving writes `st->prog`.
- `lsdj.c`: the save size from the header; a flash save of the other program is not loaded (status note); REC saves
  as the installed program; kits LSDj only; messages "NOT LSDJ OR DMGO".
- `lsdj_xfer.c`: `info` ends `prog P size SSSSS`.
- Tests: `lsdj_store_test.c` (prog kept, old records LSDj), `lsdj_xfer_test.c` (info).

### Task 4: the install tool
- `lsdj_wasm.c`: `lw_prog()`; the save size per program. `lsdjinstall.js`: `makeCart` by program (DMGo: 600
  frames, the step check, no demo). `lsdj_install.html`: text, DMGo link, the other-program warning.
- Tests: `web/test_lsdjinstall.mjs` / `lsdj_install_test.py` DMGo path with `DMGO_ROM`.

### Task 5: the simulator
- `web/sim/app.js`, `controls.js`, `index.html`, `lsdjsim.c`: DMGo ROM and 32 KiB save; X / Z = the program's A / B.
- Tests: `lsdj_sim_test.mjs` DMGo path.

### Task 6: the song page
- `lsdjlink.js`: `info` prog / size; `downloadSav` / `uploadSav` by size; `lsdj.html`: DMGo shows the save backup
  only.
- Tests: `lsdj_song_test.mjs` (DMGo info: no song list, 32 KiB up/down).
